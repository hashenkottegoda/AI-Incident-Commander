# AI Incident Commander — dashboard

React + TypeScript + Tailwind frontend for the AI Incident Commander backend: incident list,
live investigation trace, evidence/root-cause view, human approval actions, and evaluation
results. See the repository root README for the project overview.

## Commands

```bash
npm ci           # install dependencies
npm run dev      # start the Vite dev server (expects the API at http://localhost:8000)
npm run lint     # oxlint
npm run build    # tsc -b && vite build
```
